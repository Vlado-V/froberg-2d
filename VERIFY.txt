Lean project verification

From the repository root, with Git LFS and Elan/Lake installed:

  git lfs pull

  lake build
  lake env lean Audit.lean

The toolchain and external dependencies are pinned by lean-toolchain,
lakefile.toml, and lake-manifest.json. Lake retrieves the dependencies.
The default build includes every local Froberg module. OAI and Quartic
sources are included. Keep certificates/: its data are required inputs to
the kernel-checked finite proofs. If those binary inputs change, use a
fresh project build directory because their file reads are not tracked
by Lake's dependency graph.

Main theorem:
  Froberg.mainStatement (K : Type) [Field K] [CharZero K] : Froberg.MainStatement K

Entry point: Froberg/EndToEndAssembly.lean
Statement: Froberg/Statement.lean
Quotient model: Froberg/QuotientModel.lean
Positive truncation: Froberg/HilbertSeries.lean

Audit.lean uses Lean's standard axiom collection. It checks all local
supporting/generated theorems and reports the main theorem's axioms.
The permitted axioms are propext, Classical.choice, and Quot.sound.

An optional, more expensive direct dependency traversal is available:

  lake env lean DirectAudit.lean

This repository contains the paper, Lean sources, configuration, required
certificate data (stored with Git LFS), and source-provenance notes.
It contains no build cache.
